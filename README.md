# Tecmo-Super-Bowl-Scout
A live Tecmo Super Bowl scouting and stat-tracking application for Windows. It reads Nestopia memory in real time to display player conditions, ratings, team strength, and win probability while automatically tracking plays, drives, player/team statistics, passing analytics, play calls, and detailed play-by-play—without requiring manual save states.

This is a RELEASE only repository. Releases can be found on the right. Please download **`tsb_scout_BETA_1.zip`** above to get the compiled app and folders/images.
